# test-repo (SKMZ)

Agent guidance for FlatFilers/test-repo. Generated by Obvious onboarding on 2026-08-24.

A web app for querying programmers by skill via a GraphQL API. Two apps in one repo:
`server/` (Go GraphQL API) and `webapp/` (React SPA), backed by MongoDB.

## Stack

| Layer | Technology | Notes |
|---|---|---|
| Backend | Go (module declares go 1.13), gqlgen v0.10.2 | GraphQL API at `/query`, playground at `/playground`, port **8080** |
| Frontend | React 16.12, react-scripts 3.3.0 (CRA), Apollo Client | Dev server on port **3000** |
| Database | MongoDB (`programmers` DB, `programmers` collection) | Port **27017**; seeded from `server/db/mongo.init` |
| Packaging | Docker + docker-compose | Production image builds webapp and serves it from the Go server |

### Environment variables

| Var | Where | Meaning |
|---|---|---|
| `profile` | server | `prod` → Mongo host `db` (compose); anything else/unset → `localhost:27017` and CORS disabled (dev) |
| `REACT_APP_API_URL` | webapp | GraphQL endpoint base; `.env.development` sets `http://localhost:8080` |

## Commands

Prerequisites: Go, Node.js + npm, MongoDB (Docker + Compose for the repo's documented path).

```sh
# 1. Start + seed MongoDB on :27017 (documented path)
docker-compose -f docker-compose-dev.yml up -d
#    Without Docker (sandbox path): start mongod, then seed:
#    mongosh mongodb://localhost:27017/programmers server/db/mongo.init

# 2. Start the API on :8080 (from server/)
cd server && go run server.go

# 3. Start the webapp on :3000 (from webapp/)
cd webapp && npm install && npm start
```

> Node 17+ gotcha: react-scripts 3.3.0 (webpack 4) needs
> `NODE_OPTIONS=--openssl-legacy-provider` or the dev server/tests fail with
> `ERR_OSSL_EVP_UNSUPPORTED`.

### Tests

```sh
cd server && go test ./...                                  # Go: skmz, cors, db, gql
cd webapp && CI=true npm test -- --watchAll=false           # Jest: 2 suites, 3 tests
```

There is no separate lint/typecheck command; CI (.travis.yml) runs the two test suites only.

### Production

```sh
docker-compose up   # builds Dockerfile (webapp build + Go build), serves everything on :8080
```
