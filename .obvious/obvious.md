## What this repo is

A web application that queries programmers and their skills via a GraphQL API
(upstream project: SKMZ by Shpota). Go + gqlgen backend, React frontend, MongoDB database.

## Stack

| Layer    | Technology               | Version notes                             | Port  |
|----------|--------------------------|-------------------------------------------|-------|
| API      | Go + gqlgen (GraphQL)    | `go 1.13` module; builds with Go 1.23.4   | 8080  |
| Web      | React (Create React App) | react-scripts 3.3.0, React 16.12, Node 20 | 3000  |
| Database | MongoDB                  | 4.2.2 (pinned in docker-compose-dev.yml)  | 27017 |

## Commands

### Local development (canonical, per README; requires Docker for the DB)

```sh
# 1. Start MongoDB on :27017 — auto-seeds from server/db/mongo.init
docker-compose -f docker-compose-dev.yml up

# 2. Start the GraphQL API + playground on :8080
cd server && go run server.go

# 3. Start the React dev server on :3000
cd webapp && npm install && npm start
```

## Gotchas

- **Node >= 17 + react-scripts 3.x**: webpack 4 uses md4 hashing; `npm start` and
  `npm test` need `NODE_OPTIONS=--openssl-legacy-provider`.
- The Go server serves static files from the absolute path `/webapp` — that path only
  exists inside the production Docker image, so `/` returns 404 in dev. Use the webapp
  dev server on :3000; `/query` and `/playground` on :8080 always work.
- `go vet ./...` flags unkeyed `bson.D` composite literals in `server/db` — pre-existing
  style issue; builds and tests are unaffected. Use `go test` as the gate (CI does too).
- The webapp has no standalone lint/typecheck scripts; ESLint config is embedded in
  react-scripts.
