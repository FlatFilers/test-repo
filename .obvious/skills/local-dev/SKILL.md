# Local Dev — SKMZ (test-repo)

Record of the 2026-08-24 onboarding run. Stack: MongoDB (seeded) → Go/gqlgen API (:8080) → react-scripts webapp (:3000).

## What the sandbox provides

- Toolchain: go 1.27, node v20.20.2, npm 10.8.2, mongod 7.0.16 + mongosh, gh CLI (authed).
- **No Docker** — `docker-compose` is unavailable. Run mongod directly instead (below).
- `webapp/node_modules` pre-installed; Go module cache warm.
- Headless Chrome for Testing at `/home/user/work/chrome/chrome-linux64/chrome` (+ `choreographer` Python CDP client) for browser verification. If Chrome libs are missing: `sudo apt-get install -y libnss3 libnspr4 libatk1.0-0 libatk-bridge2.0-0 libcups2 libxkbcommon0 libatspi2.0-0 libdbus-1-3 libdrm2 libgbm1 libasound2t64 libxcomposite1 libxdamage1 libxfixes3 libxrandr2`.

## Bring-up sequence

```sh
# 1. MongoDB (skip if already listening on 127.0.0.1:27017)
mongod --dbpath /home/user/work/mongo-data --port 27017 --bind_ip 127.0.0.1 --logpath /home/user/work/evidence/mongod.log --fork
# Seed (idempotent-ish: drops nothing; re-run only on a fresh dbpath):
mongosh mongodb://localhost:27017/programmers server/db/mongo.init
# Verify: expect 8 documents
mongosh --quiet mongodb://localhost:27017/programmers --eval 'db.programmers.countDocuments({})'

# 2. API on :8080 (from server/)
cd server && go build -o /tmp/skmz-server . && /tmp/skmz-server &
# (or: go run server.go)  — profile unset → connects to localhost:27017, CORS on

# 3. Webapp on :3000 (from webapp/) — legacy provider REQUIRED on Node 20
cd webapp && CI=true BROWSER=none NODE_OPTIONS=--openssl-legacy-provider npx react-scripts start &
```

Check for leftover listeners first (`ss -tlnp | grep -E '27017|8080|3000'`) — a previous session's processes may still be up; reuse them if healthy rather than restarting.

## Verify

```sh
# API
curl -s -X POST localhost:8080/query -H 'Content-Type: application/json' \
  -d '{"query":"{ programmers(skill: \"go\") { name company } }"}'
# expect: Tobi Schmidt (Amazon), Bob Dogman (Doggy Inc.)

# Tests
cd server && go test ./...
cd webapp && CI=true NODE_OPTIONS=--openssl-legacy-provider npx react-scripts test --watchAll=false
```

Browser flow (primary user flow): load http://localhost:3000 → 8 programmer cards render; type `go` into `#search_string` → filters to 2 cards. Reference script: `/home/user/work/evidence/browser-flow.py` (choreographer; note `create_tab` must not pass width/height on Chrome 142 — use `Emulation.setDeviceMetricsOverride` after).

## Gotchas

- **`NODE_OPTIONS=--openssl-legacy-provider`** — react-scripts 3.3.0/webpack 4 uses md4 hashes, removed in Node 17+. Without it: `ERR_OSSL_EVP_UNSUPPORTED`.
- `npm install` with npm 10 rewrites `package-lock.json` (lockfileVersion 1→3) — **do not commit** that drift; `git checkout -- webapp/package-lock.json` before opening PRs.
- `server/gql/gen/` is generated by gqlgen — regenerate via `gqlgen` (see `server/gqlgen.yml`), don't hand-edit.
- The Go server also serves `/webapp` static files in the prod image only; in dev the webapp runs on its own :3000 with `REACT_APP_API_URL=http://localhost:8080`.
- Pictures load from pexels.com (external) — may be broken offline; names/companies/skills come from MongoDB and always render.
